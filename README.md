# سیستم تخصیص واحد — Next.js + Supabase

## فایل‌ها
- `app/page.jsx`: صفحه اصلی و بارگذاری اولیه اطلاعات
- `app/actions.js`: خواندن و تغییر اطلاعات از سمت سرور
- `components/UnitAllocationApp.jsx`: رابط کاربری و تعاملات
- `lib/supabase/server.js`: ساخت کلاینت Supabase
- `app/globals.css`: استایل‌ها
- `supabase/schema.sql`: ساخت جدول‌ها و تولید واحدها

## راه‌اندازی
1. Node.js نسخه LTS نصب باشد.
2. در پوشه پروژه اجرا کنید:
   ```bash
   npm install
   ```
3. فایل `.env.example` را به `.env.local` تغییر نام دهید و مقادیر Supabase را وارد کنید.
4. محتوای `supabase/schema.sql` را در SQL Editor پروژه Supabase اجرا کنید.
5. اجرا:
   ```bash
   npm run dev
   ```
   سپس `http://localhost:3000` را باز کنید.

## نکات مهم قبل از استفاده واقعی
- این نسخه برای شروع انتقال و مرتب‌سازی ساختار است، نه انتشار امن نهایی.
- طبق درخواست فعلی، ورود مدیر پیاده‌سازی نشده است. در نتیجه باید قبل از انتشار عمومی درباره دسترسی افراد به عملیات نوشتن تصمیم بگیرید.
- برای محیط عملیاتی، احراز هویت مدیران و RLS لازم است. هرگز `SUPABASE_SERVICE_ROLE_KEY` را به کد سمت مرورگر ندهید.
- محدودیت‌های `UNIQUE` در دیتابیس از تخصیص یک فرد به چند واحد و تخصیص یک واحد به چند فرد جلوگیری می‌کنند. عملیات هم‌زمان باید در محیط واقعی نیز تست شود.
- واردکردن JSON عمداً فعال نشده؛ ورود مستقیم نسخه قدیمی نیازمند اعتبارسنجی و نگاشت شناسه‌هاست.
- اسکنر در مرورگر به HTTPS و اجازه دوربین نیاز دارد.
- چاپ بارکد در این پیش‌نویس به‌صورت گرافیکی ساده است و هنوز خروجی SVG واقعی JsBarcode نیست؛ این بخش باید پیش از استفاده عملیاتی تکمیل شود.
- صفحه فعلاً پس از هر عملیات موفق برای گرفتن وضعیت تازه از سرور reload می‌شود؛ در مرحله بعد می‌توان آن را با به‌روزرسانی state بهینه کرد.
